## 1. 选择游戏角色

- 开局前可以选择不同的角色（目前只有一位阴阳师）。
- 待定：角色之间只是外观不同，还是各自带不同的技能 / 属性；如何解锁（段位、成就、初始全开）。

## 2. 游戏模式

在现在的玩法之外，增加模式选择：

- **无限挑战模式**：就是现在的模式，一直跑到被抓住为止，拼分数和段位。
- **每日模式**：每天一局固定的挑战，所有人当天遇到的题目和妖怪顺序相同（用日期做随机种子），方便互相比较。
- **闯关模式**：一关一关地推进，每关有明确目标（例如消灭多少妖怪、打倒头目），过关解锁下一关。

## 3. 角色左右移动

- 允许角色在三条路之间左右移动。
- 用途：躲避妖怪 / 障碍，或者主动去撞道具（加血、充技能等）。
- 待定：操作方式（键盘方向键、手机滑动，同时不能和在符纸上写字冲突）、道具种类、和现有"答案命中同一答案的所有妖怪"机制怎么配合。

## 4. 完善开局教学（tutorial）

现在的开局教学只教了"看算式 → 在符纸上写答案 → 发送"，还缺下面几块：

- **技能教学**：技能怎么充能（消灭妖怪），充满后怎么释放（点技能印 / 按 F），以及四种技能各自的效果：时停·封、雷神、护身结界、招福。
- **主题之夜（夜晚事件）教学**：每种夜晚有什么效果、该怎么应对，例如满月之夜（分数 ×2、妖怪更快）、夜雾之夜（妖怪离得更近才出现）、赤月·百鬼过境 / Blood Moon（妖怪更多）、狐火之夜（技能充能 ×2）。
- **特殊妖怪技能教学**：会左右飘的、会闪到别的路上的、看不见算式的（无脸）、三只一组的、会突然冲刺的、要打好几次的、出现得晚的等等，各自怎么识别、怎么应对。
- 待定：全部放进开局教学会太长。可以考虑开局只教基础和技能，夜晚和特殊妖怪在第一次遇到时再做简短的现场教学（现在第一次遇到特殊妖怪时会有一张小提示卡，可以在这基础上扩展）；另外在"玩法说明"里提供可以随时重看的教学。
